Setting up a Windows XP computer in 2026 - Part 2 - The Software

BIOS SETUP

The bios was by far the most challenging aspect of the installation. As I've described on the Part I article[1], the motherboard did not had specific details of the manufacturer available, besides just one small paper sticker. As this was the initial (and only) clue that I had, there was much to discover (and guess) on how to update the bios of this computer. I tend not to mess with BIOS around when not needed, but the main problem of this setup is that the NVIDIA GEFORCE GT 710 that I bought was not outputting video from neither the HDMI nor the VGA ports.

After further analysis, the old BIOS version was using a legacy BIOS that expects a 16-bit real-mode option ROM. Many GeForce 700-series and newer cards ship with a UEFI-only or hybrid VBIOS that legacy firmware fails to initialize, resulting in a black screen, no POST, or the system falling back to integrated graphics. The old BIOS version did not have a toggle between UEFI and Legacy/CSM (Compatibility Support Module) which was required to be enabled so the GT 710 could communicate correctly for outputting video.

The update process for the H61H2-M2 is not simple. It involves following multiple procedures that requires clearing the CMOS and jumping the ME_UNLOCK pins. This is fully described on this guide[2], which was created to help users install Windows 8. The most critical step was to identify which version the board was on this build, since there were two main ones being manufactured for SEMP TOSHIBA during this time. The only way to identify is to check the model of the ROM embedded on the board, which had different memory sizes. The only way (besides checking the version printed on the board, if available) to distinguish them is by running a tool like CPU-Z or by checking the backup/dump file size when saving the existing BIOS (V1.0 generates a file under 4MB, while V2.0 generates a file larger than 4MB, typically around 6MB–8MB). Running CPU-Z on SEMP TOSHIBA machines DOES NOT give you this information because they renamed the BIOS and changed the boot screen logo to theirs, so the only way to identify is by the output file size.

Setting up windows xp

After resolving the issue with the BIOS and the compatibility of the video card, there was one last small adapting needed via BIOS, which was doe to enable the installer to recognize the Hard Drive by changing the SATA driver properties to Legacy Mode, instead of AHCI


Once that was done, setting windows XP was pretty straight forward, just following the installer steps.
